OrganizerVendor dashboard

Search company details, product rows and document text from the connected Drive folder. Original files stay in Google Drive.

Paste a Google Drive folder or ZIP file link below, including ZIPs over 10 GB. ZIPs are read in small ranges; originals are not copied into PostgreSQL. The link must allow the server to read files without signing in. Limits: 5,000 entries per ZIP, 128 MB per extracted document, and available database space. Image text needs OCR; check Files & issues for anything not fully searchable.

Saved records remain searchable when you add another link. Everyone with dashboard access shares the selected source and records.

Connecting…

Rows are extracted source data awaiting review; they are not automatically approved catalogue products. Progress and rows are shared in PostgreSQL. Signed sessions renew while this page is open. A server restart requires Resume; a storage pause requires more database space. Entries needing OCR, unsupported formats, oversized files and failures remain visible.
